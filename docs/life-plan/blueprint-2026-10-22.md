# Self-growth system blueprint (from the user, 2026-10-22)

The user's instruction: "use that definition as blue print and improve current app." It is kept here verbatim so every phase works from the same text. Where it conflicts with the app's existing tuned rules, the user's decisions are recorded at the end of this file (the "Decisions" section).

---

self-growth Daily Task System requires converting abstract personal goals into a deterministic state machine with zero-latency feedback, anti-inflationary XP scaling, and strict biological decay controls. Based on behavioral psychology research (Phillippa Lally et al., University College London, European Journal of Social Psychology, 2009, which established a median 66-day threshold for automaticity) and goal-setting theory (Locke & Latham, American Psychologist, 2002, demonstrating a 16% to 25% performance delta via high-specificity telemetry), your system must enforce these core architectural requirements.

1. Ontological State Engine (The Status Panel)

* Target Avatar Baseline: Define the exact quantitative parameters of your "Desired Self" across 4–5 Orthogonal Attributes (e.g., Physique/Vitality, Cognitive/Quant Engineering, Capital/Sales Velocity, Discipline/Willpower).
* Logarithmic Leveling Curve: Prevent early-stage dopamine burnout and late-stage inflation by governing Attribute Levels ($L$) via a power-law XP requirement:
$$\text{XP}_{\text{required}}(L) = \text{Base} \times L^{1.5}$$
* Skill Proficiency Trees: Separate Attributes (hardware) from Skills (software). Track repeatable competencies using discrete volume tiers (e.g., Tier 1: 0–100 hours, Tier 2: 100–500 hours, Tier 3: 500–2,000 hours).

2. Algorithmic Quest Engine (Task Hierarchy)

* Main Quests (Epoch Milestones): Multi-month structural objectives broken down into deterministic weekly sprints.
* Daily Quests (Non-Negotiable Baseline): Binary ($1/0$) daily habits capped at 3 to 5 core actions per day (e.g., strength training, deep-work block, reading quota) to prevent cognitive overload (Iyengar & Lepper, Columbia/Stanford choice overload study, 2000).
* Triggered / Side Quests: High-yield opportunistic tasks generated by real-world anomalies or sudden high-leverage opportunities.
* Time-in-State Verification: Reject simple checkbox completion for deep work; require proof-of-work telemetry (e.g., logged minutes, git commits, pages processed, or volume lifted) before minting XP.

3. Biological Decay & Drawdown Controls (Anti-Cheat)

* Ebbinghaus Proficiency Decay: Unlike fictional systems, human biology degrades. Apply a daily decay constant ($\lambda = 0.005$ to $0.02$) to unpracticed skills after a 72-hour inactivity grace period, modeling synaptic and muscular atrophy (Hermann Ebbinghaus, Memory: A Contribution to Experimental Psychology, 1885).
* Streak Multipliers & Shields: Apply a compounding XP multiplier ($1.05\times$ per consecutive day, capped at $2.0\times$ at Day 14). Missing a Daily Quest resets the multiplier to $1.0\times$ and deducts a flat HP/Willpower penalty unless an earned "Rest Token" is consumed.
* Fatigue / Burnout Circuit Breaker: Cap daily maximum XP generation. Exceeding safe daily cognitive or physical output triggers a diminishing-returns penalty ($0.5\times$ XP) to enforce sleep and recovery compliance.

4. Closed-Loop Token Economy (The System Mall)

* Dual-Currency Ledger: Mint XP (immutable, permanently bound to Attributes/Skills) and System Credits (spendable liquid currency earned via quest completion).
* Guilt-Free Reward Clearinghouse: Lock all discretionary leisure, luxury purchases, or entertainment behind the System Mall. You cannot consume the reward unless you burn the exact System Credit balance earned from productive output (Variable Ratio reinforcement per B.F. Skinner, Schedules of Reinforcement, 1957).

5. Low-Friction Telemetry & Audit Layer

* Sub-5-Second Ingestion: The UI/UX must allow logging a completed task in under 5 seconds (via 1-click HUD gates, mobile shortcuts, or automated webhooks) so tracking friction never exceeds execution friction.
* Weekly Hostile Audit: Automate a Sunday night state reconciliation that calculates weekly completion rate (target $\ge 85\%$), highlights decaying attributes, and auto-calibrates quest difficulty for the upcoming week.
